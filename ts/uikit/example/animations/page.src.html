@evinvest/uikit : animations

Real kit CSS: ts/uikit/styles/tokens.css (= repo-root tokens.css + theme.css + motion.css) + Tailwind v4 + tw-animate-css, compiled over the kit's own generated class strings (src/generated/*.ts) into kit.css. Each element carries the real data-slot / data-state / classes.

1 · Toasts

Toast stack: enter, collapse, hover-expand, close, auto-dismiss

motion.css:20-181 ([data-slot=toaster][data-stack]). Enter: ev-toast-enter 350ms cubic-bezier(.21,.8,.4,1) backwards (translate from 100% + fade). Restack: transform 350ms same easing, opacity 350ms, height 350ms. Close: data-state=closed slides to --enter-y + fades, node dropped on transform transitionend. Collapsed: back toasts lift by --gap*index, scale 1-index*.05, only front 3 visible. Hover/focus on the stack: spread to --offset (pure CSS). Auto-dismiss: no-op ev-toast-life animation for --life (4s here), animationend closes; hover pauses it (animation-play-state 2nd slot). Reduced: opacity-only 200ms enter, transform 1ms.
Note: the React port's Toaster auto-dismisses with setTimeout (sonner.tsx), not the CSS life animation; the life animation is the shared-CSS path (Dioxus). Layout vars (--index, --offset, --initial-height, --front-height) are computed by the same arithmetic as sonner.tsx.
